# DeeperTR

Bu repo frontend ve backend uygulamalarını tek bir monorepo altında toplar.

## Yapılan iyileştirmeler

- Frontend: Zod ile form doğrulama, React Query ile cache/invalidation ve hata/boş durum bileşenleri.
- Backend: Global validation pipe, merkezi exception filter, request logging middleware, rate-limit ve Swagger.
- CI: Monorepo genelinde lint + format kontrolü + type-check zorunlu.
