# UI Package

## Icons
- `icons/filled`: filled SVG icon set
- `icons/outline`: outline SVG icon set

## Tokens
- `src/tokens.css`: color, spacing, radius, shadow and typography tokens.
- Dark theme is default (`:root`, `[data-theme='dark']`).
- Future theme overrides can be added with `data-theme` selectors.

## Visual Utilities
- `src/visuals.css`: gradient, blur, glow and grid pattern utilities built with CSS gradients/filter.

## Containers
- `PageContainer`
- `SectionContainer`
- `CardContainer`
- `PanelContainer`
